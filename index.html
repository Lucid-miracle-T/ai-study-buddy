该请谁教你

把要学的内容写进来（已按当前章节预填），再点一点你现在的状态，下面会推一位最合适的导师。
推荐看的不是「谁教哪一科」——所有人格都与学科无关——而是这块内容的性质（吃定义？吃图形？吃适用条件？）加上你现在的状态（基础不牢？怕假懂？学过忘了？）。
所以同一门课，学定义那节可以请柯西，学几何应用那节换成莱布尼茨，都很正常。
全部在这台设备上算，不耗 token；自定义人设不参与推荐。

导师人格

点一个再改提示词；改动会记住。每一节各自记着自己的导师——换节就换人，互不牵连；新开一节默认沿用当前这位。

本轮模式

人格决定「怎么说话」，模式决定「这一轮干什么」——想被考就切陪练，做完题想查错就切批改。上课页顶部也能切，两边同步。

操作习惯

改完立刻生效，存在这台设备上。习惯是你自己的，换教材、换课程都不会动它。
中文输入法打字时按 Enter 是在选字，不会被当成发送——这点已经处理好了，不用担心打一半被送出去。

想改自己说过的话？点你那条消息右上角的「编辑」，改完点「重发」——它之后的内容会一起清掉，导师会拿改过的话重新回答一遍。要是只错了个符号，这比重新问一遍省事得多。

动作描写：导师写成 *推了推眼镜* 的句子是旁白，会显示成浅色小字，和它要讲的话分开。你自己也能这么写——旁白不会被朗读出来。想改在哪几个角色身上出现，就在上面这个开关里调。

加自己的人设

内置的只有三位数学家和五位鸣潮角色。想让谁陪你学，自己填一个就行——加完会出现在上面那排。

给你的教学规则

这段会自动附加在每次提问后面——来自你在破卷里积累的学习记录。

当前教材

这句会自动告诉导师"以哪本书为准"。按课程分开保存：高数课填高数的书名，线代课填线代的，互不影响——这就是之前"导师说教材对不上"的原因。
所有人格都与学科无关：柯西管严格性、莱布尼茨管直觉、牛顿管物理意义、相里要管适用边界
—— 学线代、概率论、C 语言都适用。换教材只需要：这里改书名 → 教材页导入 → 左上角切到那门课。

内置了 3 位数学家和 5 位鸣潮角色。想要别的，在「加自己的人设」里填一段提示词就行。

课程管理

课程是从教材推出来的：载入哪本教材，课程栏就多一门课。
清空记录只把这门课的对话、闪卡、掌握进度归零，教材和勾选的章节留着，随时能重新开课； 删除课程连教材正文一起移除，这门课从课程栏消失（内置教材之后还能再载入回来）。

数据

教材正文存在浏览器 IndexedDB，其余（对话、闪卡、进度、习惯、接口配置）在 localStorage。清浏览器数据、换设备、或在不同的链接之间切换，这些都带不过去——所以重要的时候先导出一份。
导出的是全部对话、闪卡、掌握进度、勾选、习惯设置、导师与接口配置；不含 API Key，也不含教材正文（换设备后重新「载入全部内置教材」即可）。

换手机、换浏览器、清缓存之前先导出一次；在新环境里点「从备份恢复」选中那个文件，记录就回来了。

语音

像 Socratopia 一样全程开口：点麦克风说话（识别依赖 Chrome / Edge）；导师可用系统中文音色把回答读出来。朗读走系统自带音色，不耗 token。公式、代码会自动跳过不读。

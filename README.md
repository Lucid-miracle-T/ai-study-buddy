# ai-study-buddy · 无穷之境

一个**纯前端、零后端**的 AI 陪学站。把教材丢进去，选一位导师，它会按你选的"这一轮干什么"带你学——而不是一上来就把答案讲给你听。

- **在线体验**：https://lucid-miracle-t.github.io/ai-study-buddy/ —— **精简版**：前三位导师（柯西 / 莱布尼茨 / 牛顿）、不含内置网课；教材给一份**自制示例讲义**（真教材正文受版权限制，不随仓库分发）。完整的「三本教材 + 八位导师 + 网课」走下面的备用入口
- **备用入口（完整版）**：https://gaoshu-xuexi.app.workbuddy.host/
- **技术形态**：单个 `index.html`（约 200 KB）。无框架、无构建、无后端；**站点本身零依赖**，只有跑测试才需要装 jsdom

## 跟普通 AI 聊天有什么不一样

| | 说明 |
|---|---|
| **人格 × 模式** | 人格决定"怎么说话"，模式决定"这一轮干什么"。换人格不改任务，换模式不改风格 |
| **教材按需进上下文** | 默认不带整本书，只发你勾选的那几节。省 token，导师也不跑题 |
| **多教材完全隔离** | 每本教材有独立的对话、进度、上下文勾选、闪卡，切走再切回来原样恢复；**导师正在回答时切走也不会打断**——回答照旧写完、存回原课程，切回来就在 |
| **课程内分节** | 课程标签是「一本书」（少而稳），下面是「节」（想开多少开多少）：每节自己的对话、闪卡、小结，切回第 2 节看到的就是第 2 节的东西。发给导师的上下文只含当前节——不会越聊越长。节可改名、可删；升级前的旧记录自动归入第一节 |
| **闪卡 Leitner 间隔复习** | 6 格：5min → 12h → 1d → 2d → 4d → 8d |
| **网课栏目** | 内置翁恺 C 语言（132 讲）与两套江协 STM32（**在线体验版不含**）；讲义按 `[mm:ss]` 分段，点时间戳跳回视频对应时刻；可做整份合集的分析报告 |
| **公式渲染** | KaTeX 五源 fallback，全挂了降级为可读文本；内置符号面板（Ctrl+M），模板插进已有公式里不会再套一层 `$`（那会把一段公式拆成两个残段，KaTeX 只能把原文用红字吐回来） |
| **说过的话能改** | 自己那条消息点「编辑」→「重发」，之后的内容截断后重新回答；中文输入法选字时的 Enter 不会被当成发送 |
| **导师有动作和神态** | 导师讲课时会顺带写一小句旁白（`*推了推眼镜*`），显示成浅色小字，和它要讲的话分开；朗读时旁白会被跳过 |
| **下指令前先自检** | 导师让你做操作时必须点名对象（写「第 2 行」而不是「某一行」）、核对行/列方向、操作式先自己验算；发现自己说错了要先认「是我说错了，不是你做错了」，再作废错方向并指出从哪一步重来 |
| **问的是判断，不是算术** | 导师不会拿「5 − 3×2 等于几」考你——一步出数的加减乘除它自己算完写出来；要问就问「该动第几行」「系数为什么取这个数」。例外：本节练的就是算（速算、单位换算、矩阵乘法手算），或你说了想自己动手算 |
| **缺字兜底** | 模型直接吐 Unicode 数学样式字母（`𝑘`）时先按 NFKD 归一化成 ASCII（`k`）；剩下的缺字标点状下划线、悬停显示码位——方框不再是谜 |
| **刷新回到最后一句** | 重新打开时自动停在最后一次对话；公式后到、地址栏收合导致内容变高也跟到底，你一滚它就松手，滚回底部又接上——不把人往回拽 |
| **课程管理** | 设置页列出全部课程和各自的教材节数 / 对话条数 / 闪卡张数 / 掌握节数：**清空记录**只把对话、闪卡、掌握进度归零（教材和勾选留着，随时重新开课），**删除课程**连教材正文一起移除、课程从课程栏消失（内置教材之后能再载入回来） |
| **操作习惯** | 设置页可改：发送方式（Ctrl+Enter / Enter）、**导师一次问几个问题**（一次一问 / 一次 2–3 问）、**导师的动作与神态描写**（关闭 / 自然 / 丰富）、对话字号（标准 / 大 / 特大）、符号面板是否默认展开 |
| **PWA** | 可"添加到主屏幕"，全屏无地址栏；移动端已适配 |
| **数据备份** | 一键导出全部学习记录为 JSON（**不含 API Key**），换设备/清缓存后「从备份恢复」带回 |

**五个教学模式**：讲解（默认）／陪练出题（只出题不提示，答完才判）／批改我的解答（按阅卷标准给分 + 逐条标硬伤）／考试视角（题型、分值、得分点、失分点）／工程接口（接到专业课，带单位的真实算例）。

## 三步跑起来

1. **设置** → 填一个 OpenAI 兼容的模型接口（base URL + key + 模型名），保存
2. **教材** → 把正在学的那节勾上
3. **上课** → 选人格、选模式，点「开始今天的一课」

第 2 步的教材从哪来，取决于你在哪种环境：

| 你在哪 | 教材从哪来 |
|---|---|
| **线上站点**（上面两个链接） | 自动载入：主站三本（高数 / 线代 / C 语言，46 个分册），体验版只列高数一本 |
| **自己 clone 这个仓库** | 仓库**不带教材正文**（版权原因，见下面「版权」）。打开会自动载入一份**自制示例讲义**（极限与导数入门，5 节），让你先看见完整流程；真要上课，点「导入教材」放自己的 md / txt / pdf / epub 进来 |
| **自己部署、且本地有 book/** | 把教材 md 放进 `book/`，点「载入全部内置教材」 |

内置网课包（`video/`）是随仓库分发的，clone 下来「网课」栏目就能用。

（首次打开会自动补下教材与网课包，几十个文件，慢一两秒属正常。）

### 免费上手

智谱 GLM 的 `glm-4-flash` 永久免费，注册另送额度。预设里已内置智谱、火山引擎、DeepSeek、硅基流动、阿里百炼、OpenRouter 六家的地址，选一家填 key 即可。

### 本地运行

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也能用大部分功能，但 `file://` 协议下读不到 `book/` 目录、也装不了 PWA，建议起个静态服务。

> **别给这个仓库加 `start` / `serve` / `dev` 脚本。** 它是纯静态站，云平台靠 `index.html` 就能托管；一旦 `package.json` 里出现启动脚本，平台会把它当 Node 应用，按脚本里的端口（比如 8000）起服务，而平台探的是注入的 `$PORT`（3000），于是永远报「服务没有在指定端口上响应」。`package.json` 里只留 `test` 就行。

## 隐私

- **代码里没有任何密钥**。你填的 API key 只存在自己浏览器的 localStorage
- 页面**直接请求你填的那家 API**，不经任何中间服务器
- 教材正文、对话、进度、闪卡全在你自己设备上。清浏览器数据会一起没，重要的话用设置页「导出全部数据」备份

## ⚠️ 提交前必读：版权

**本仓库不包含任何教材正文**，`book/` 已在 `.gitignore` 中排除。

请不要把受版权保护的教材全文提交进来——那是侵权，会连累整个仓库被 DMCA 下架。教材由使用者**自己导入**，本仓库只提供承载工具。

**唯一的例外是 `book/示例/`**：那里放的是自己写的示例讲义（`极限与导数入门.md`，5 节），不摘录任何出版物，随仓库分发，让新 clone 的环境开箱就有课可上。`.gitignore` 里写的是 `book/*` + `!book/示例/`，专门给这个目录留了口子——**别把真教材搬进这个目录**，那等于绕过了整条版权约束。

想内置教材自用：把 md 放进 `book/`（子目录也行），页面点「载入全部内置教材」。代码里 `const PACKS` 声明每门内置课叫什么、由哪些文件组成——多个文件会自动合并成一门课，不会拆成一堆对话框；它不会被 git 跟踪。

取教材用的是 `cache:'no-store'`，且**首次一无所获时启动流程会自己再试一轮**——因为部署的那一两分钟里沙盒正在重启，取 `book/*.md` 会整批失败，而失败的响应一旦被缓存住，之后刷新多少次都是空的。真的一份都取不到时，教材页的空状态里会直接放一个可点的「载入全部内置教材」，不留一块「点了没反应」的空地。

⚠️ **两个包的 `files` 里不能出现同名分册**（例如两门课都想叫 `附录.md`）：分册是靠文件名判归属的（`packOf`），重名会整本被判给前面那个包。C 语言的附录因此叫 `附录 A-F.md`。

`video/` 里是网课包（课程目录 + B 站自动字幕），随仓库分发，所以「网课」栏目换设备也在。如果你觉得字幕不该开源，把 `video/` 加进 `.gitignore` 即可——那时内置网课只在部署了 `video/` 的站点上出现。

## 关于角色人格

内置 8 位导师：柯西、莱布尼茨、牛顿（历史数学家），以及 5 位鸣潮角色风格人格（爱弥斯、维里奈、长离、相里要、守岸人）。

**在线体验版只开放前三位**（历史数学家那三位）——访客一进来不必面对八个选择；完整版八位都能用。这个切换按域名自动完成：`github.io` 下是体验版，自有域名与本地打开是全功能版（同一份 `index.html`，见源码里的 `const LITE`）。

角色名称与形象的著作权归库洛游戏所有。本项目**仅借用其说话风格**做学习陪伴的同人向模拟，与官方无关，不含任何游戏素材。介意的话可在设置里自定义人格覆盖，或直接删掉 `PERSONA` 中对应条目。

## 参与改进

改动全部集中在单文件 `index.html`。搜这些关键字定位：

| 关键字 | 区块 |
|---|---|
| `const PERSONA` | 人格定义（说话风格） |
| `const MODE` | 模式定义（这一轮干什么） |
| `const RTYPE` / `RSTATE` / `RKW` / `RSHORT` | 「该请谁教你」：按内容性质 + 你的状态推荐导师（`rRec` 打分 / `rRank` 排序 / `renderRout` 渲染） |
| `const QDENS` / `const QDIFF` / `const ACTS` | 输出风格：提问密度、提问分量（考判断不考算术）、动作与神态旁白（`function md` 里把 `*旁白*` 渲染成 `.act`） |
| `const PACKS` | 内置教材包（哪门课由 `book/` 下哪些分册组成） |
| `let SESS` / `CURS` | 「节」：课程内部的学习单元（`loadSess` / `newSess` / `switchSess` / `delSess` / `sid` / `sessLabel`）。消息与闪卡带 `s` 字段，没有的一律算第一节 |
| `function renderSTabs` | 节条（课程标签下面那一行）：切换、`＋ 新一节`、右键/长按改名或删除 |
| `const VBUILTIN` | 内置网课包（`video/` 下的 json，首次打开自动入库） |
| `const VPOS` / `saveVPos` / `restoreVCtx` | 网课看到哪儿了：合集、第几讲、带到课堂的那一讲（上下文只存 key，正文按 key 重建）。`function goView` 顺手记下你待在哪一页 |
| `function sysMsg` | 组装发给模型的 system prompt |
| `function ctxText` | 教材摘录与来源标注 |
| `---------- 停在最后一次对话 ----------` | 滚动跟随：`isBottom` / `toBottom` / `settleBottom` / `followFor`（盯 `#msgs` 与 `#mw` 两个盒子） |
| `---------- 课程管理（设置页）----------` | `cstat` / `renderCourseMgmt` / `clearCourse` / `dropCourse` |
| `---------- 网课 ----------` | 网课栏目 |
| `const IDB` / `const VDB` | 存储（教材库 / 网课库，互相独立） |

涉及**布局和滚动**的问题，jsdom 测不了（它没有布局引擎，`scrollTop` / `scrollHeight` 恒为 0）。
这类问题用真浏览器实测，`scripts/probe_scroll.mjs` 就是为此写的：

```bash
# 起静态服务器和带调试端口的浏览器，再跑探测脚本（Edge / Chrome 都可以）
python -m http.server 8899                                   # 在项目根目录
msedge --headless=new --window-size=390,844 \
       --remote-debugging-port=9223 --remote-allow-origins=* \
       "http://127.0.0.1:8899/index.html"                    # 另开一个终端
node scripts/probe_scroll.mjs http://127.0.0.1:8899/index.html
```

它会种一段长对话，然后按时间线打印「距底部还差多少像素 / 是否在跟随」，
再模拟内容晚到和用户滚上去两种情况。「刷新后没停在最后一条」那个反复修的 bug，
就是靠它定位到真因的（**不是没滚，是滚完内容又长了 28px 而没人补**）。
